# Doceo — downloads

Official installers for **Doceo**, a local-first document, task and calendar app for Windows, macOS and Linux.

**[Download the latest release →](https://github.com/MangoDman/d0ceo-release/releases/latest)**

| Platform | File |
| --- | --- |
| Windows 10 / 11 (64-bit) | `Doceo_<version>_x64-setup.exe` (or `.msi`) |
| Linux (x86-64) | `Doceo_<version>_amd64.AppImage`, `.deb` or `.rpm` |
| macOS, Apple Silicon | `Doceo_<version>_aarch64.dmg` |
| macOS, Intel | `Doceo_<version>_x64.dmg` |

The installers aren't code-signed yet, so Windows and macOS show a one-time warning on first launch.
Install steps: https://doceo-six.vercel.app/download

This repository only hosts release binaries. Website: https://doceo-six.vercel.app
